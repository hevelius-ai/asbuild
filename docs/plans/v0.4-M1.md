Milestone M1 of `docs/plans/v0.4-plan.md` (D48). Estimate 6 to 9 agent hours; stops at 9 for the owner's choice. One pull request, `m1/engine`, branched from main at 324ce35 (M0 merged). Three-lens review under the scope guard. The kill gate counts M1 and M2 together (18 hours).

## Criteria

- **M1-C1 The seam.** `engine/langs.py` holds one row per language, keyed by the extension of the locked acceptance files: result files to read; name rule; locked-test lookup; lock test listing; story from a result; failure rules. Python's row is today's code, moved. A language is in play only when main's (or, for a story, the pull request's) `locks.json` holds a file it owns.
- **M1-C2 JavaScript results.** `junit_classify` gains the JavaScript rules by language row (design §4.4): `AssertionError` strong; the existence-only messages and file-level failures; an empty `type` unreadable (UNRESOLVED via `NO_BEFORE_RESULT`); everything else strong. `pr-js.xml`, `acceptance-js.xml` and `c3/` are read when JavaScript is in play.
- **M1-C3 Names and lookups.** `matches` splits on any non-letter, non-digit (P-ENG-1); `story_of` reads the path; the locked-test lookup finds JavaScript results by file path and title; a file that could not load counts all its checks existence-only.
- **M1-C4 The lock.** `lock_check.entry(raw, path="")`: byte-identical for `.py` (golden `locks-py.json`); for JavaScript test files, the literal titles of top-level `test(`/`it(` calls.
- **M1-C5 Protected names, scoped (L5 B).** The 13 new names, applied only when JavaScript is in play; `receipt.py` maps them to its plain phrases.
- **M1-C6 STORY_ADDS_TOOLS.** A story pull request with new JavaScript checks whose only protected changes are `package.json` and `package-lock.json`; the neutral sentence; passes `lint_plain`.
- **M1-C7 Install codes.** `js-install.txt` with `EBADPLATFORM`, `ERESOLVE` or `EUSAGE` adds one fixed sentence to the UNRESOLVED receipt; anything else adds none.
- **M1-C8 Earlier stories.** With JavaScript in play, another story's locked check that fails in `acceptance-js.xml` counts as broken unless it is an unbuilt story failing on main too.
